# Employee Attrition Analysis Dashboard | Power BI

## 📊 Project Overview

This project analyzes employee attrition using Microsoft Power BI.

The dashboard provides an interactive view of employee attrition across different departments, job roles, tenure bands, overtime status, and age groups.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel
- CSV Dataset

## 📌 Dashboard Features

- Total Employees
- Attrition Rate
- Average Monthly Income
- Average Employee Tenure
- Attrition by Department
- Attrition by Job Role
- Attrition by Tenure
- Attrition by OverTime
- Attrition by Age Group
- Interactive slicers for Department, Gender, Marital Status, and OverTime
- Key Insights section

## 📈 Key Insights

- Sales Representatives have the highest attrition rate among job roles.
- Employees with 0–2 years of tenure have the highest attrition rate among tenure groups.
- Employees working overtime have a higher attrition rate than employees not working overtime.
- Overall employee attrition rate is 16.12%.
